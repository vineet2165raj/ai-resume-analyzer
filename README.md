# AI Resume Analyzer

## Features
- ATS Resume Scoring
- AI Resume Analysis
- Skills Extraction
- Resume Preview
- PDF Report Generation
- Analytics Dashboard
- Dark Mode

## Tech Stack
Frontend:
- React
- Tailwind CSS
- Chart.js

Backend:
- FastAPI
- Python

## How to Run
Frontend:
npm install
npm run dev

Backend:
uvicorn main:app --reload
